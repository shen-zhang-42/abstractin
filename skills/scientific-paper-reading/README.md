# scientific-paper-reading

Files:

- `SKILL.md` — core skill behavior
- `REPORT-FORMAT.md` — QMD/HTML report structure
- `report-style.css` — stable reading stylesheet

Default workflow:

1. Read one scientific paper.
2. Generate a four-part QMD summary.
3. Use that summary as the primary basis for discussion.
4. Return to the original paper only when more detail or correction is needed.
5. Update the internal understanding when discussion changes interpretation.
6. Ask before externally verifying novelty/importance/field-position claims.
7. Ask whether the user wants HTML after the QMD report is complete.

The second report section — experiments, methods, results, and evidence — is intentionally the most detailed part.
